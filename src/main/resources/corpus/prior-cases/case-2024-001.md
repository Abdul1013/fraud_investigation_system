
# Case 2024-001: Account Takeover

## Summary

Customer reported unauthorized transactions totaling ₦2,300,000
across three transactions within 45 minutes. All transactions
originated from a single IP address in a different country
from the customer's usual location.

## Evidence

- Login from unknown device at 02:14 UTC.
- Three transactions at 02:18, 02:22, and 02:31 UTC.
- IP address geolocated to a known VPN exit node.
- Customer confirmed via phone that they did not authorize.

## Decision

Transactions reversed. Account frozen pending credential reset.
Case filed as confirmed fraud.

## Lessons

Device fingerprint matching alone was insufficient; IP velocity
and geo-velocity checks should be added to the detection rules.
